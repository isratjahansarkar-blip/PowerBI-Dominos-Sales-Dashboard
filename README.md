# 🍕 Power BI Domino's Pizza Sales Dashboard

## 📌 Project Overview
This project analyzes Domino's Pizza sales performance using Power BI. It provides interactive dashboards and business insights to support data-driven decision-making.

## 🛠️ Tools & Technologies
- Power BI
- DAX
- Microsoft Excel

## 📊 Dashboard Features
- Total Sales KPI
- Total Orders
- Average Order Value
- Sales by Branch
- Sales by Product
- Interactive Date Filters

## 💡 Skills Demonstrated
- Data Analysis
- Data Visualization
- Dashboard Design
- DAX
- Business Intelligence
